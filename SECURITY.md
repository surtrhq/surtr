# Security policy

Surtr will include a privileged component that reads, and later changes,
hardware settings. Please report security problems privately.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. Please don't open a
public issue for a security problem.

Include what you found, how to reproduce it, and which version or commit you
tested. We will acknowledge the report, keep you informed, and credit you in
the advisory unless you prefer otherwise.

## Supported versions

Surtr has no releases yet. Until the first release, only the `main` branch is
supported.
